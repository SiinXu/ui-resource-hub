# Teaching agents taste: how design skills de-slop AI interfaces

> Skills like frontend-design, taste-skill and impeccable package opinions as files agents load on demand. Here is how to combine them.

Blog post: https://siinxu.github.io/ui-resource-hub/blog/taste-and-skills-for-agents/

An agent skill is a folder with a `SKILL.md` the agent reads when the task matches its description. For design, that means opinions survive between sessions instead of living in one long prompt.

## A working stack

- **Direction:** 
frontend-design
 or 
taste-skill
 before writing code. They push a committed aesthetic and ban the usual tells.
- **Craft:** 
emil-design-eng
 for motion and micro-interaction judgement.
- **Audit:** 
impeccable
, 
baseline-ui
 and 
web-design-guidelines
 after a draft exists.
- **Redesign:** 
redesign-skill
 when upgrading an existing site.

## Our take

Do not load everything at once. Overlapping skills give conflicting advice. Use one direction skill, one craft skill and one audit skill per task. Write project-specific "never" rules in AGENTS.md so they override generic taste.
