# Figma Make and the Figma agent: AI moves onto the canvas

> Figma Make turns prompts into working prototypes; the Figma agent, generally available since 6 Oct 2026, reads team guideline files. Why the guideline file matters most.

Blog post: <https://siinxu.github.io/ui-resource-hub/blog/figma-make-and-figma-agent/>

Figma Make, introduced at Config 2025, generates interactive prototypes and simple apps from a prompt, and can start from an existing Figma frame. It answered the question designers kept asking about v0-style tools: "can I do this where my designs already live?"

## The agent goes GA

On 6 October 2026 Figma made its product-design agent generally available, after a beta that began in May. Two additions stand out in the coverage: library owners can supply guidelines (markdown files) that the agent reads whenever that library is enabled, and teammates can watch the agent's activity live on the canvas.

## Why the guideline file is the real feature

- It moves art direction from a per-session prompt into a file the team maintains and reviews.

- It makes AI output consistent across people, not just across one person's sessions.

- It is the same pattern as SKILL.md, Cursor rules and Lovable project knowledge: **durable, versioned design context**.

## What to put in yours

Token names and when to use each; spacing and type scales; component do/don't pairs; voice and tone for UI copy; a short "never" list (no text gradients, no emoji icons, no centred body text). Keep it short enough that a reviewer actually reads it, and link to examples rather than describing them. Our encyclopedia's spec digests are a reasonable starting template.
