# Weekly roundup, 14 Oct 2026: guideline files go mainstream

> Figma agent GA with team guidelines, Lovable drops its pick-a-look step, Magic Patterns launches MagicOS, Chrome iterates on HTML-in-Canvas. What it means for your workflow.

Blog post: https://siinxu.github.io/ui-resource-hub/blog/weekly-roundup-2026-w42/

This week's design-tool news shares one theme: the art brief is moving out of the chat box and into files and canvases that persist. Dates are from each vendor's own announcement.

## The news

- **6 Oct · Figma:** the product-design agent is generally available after a beta that began in May. Library owners can attach markdown guideline files the agent reads; teammates can watch agent activity on the canvas.

- **8 Oct · Lovable:** the three pre-build design directions are gone; the look now comes from your prompt, with clarifying questions only when it is open. Same day: nine new app and chat connectors (including Zendesk, Neon and Metabase) and a Loom chat connector.

- **13 Oct · Magic Patterns:** MagicOS, an infinite canvas with a coordinator chat that runs parallel design threads, real-time voice, and an MCP server for coding agents.

- **Chrome:** the team posted an update on the HTML-in-Canvas API, which lets canvas and WebGL draw real DOM and CSS; an origin trial is running.

## What to do with it

- Write (or tidy) your design guideline file now; three tools in one week started reading one.

- Put the style paragraph first in every app-builder prompt.

- If you explore many directions, try a canvas tool; if you polish one screen, stay in a single design.
