所有 AI 界面生成器都会收敛到训练数据的"平均值"：居中大标题、三张特性卡、一道紫色渐变。这不是 bug，而是"最可能的下一个词"的本义。结论很直接：速度已经免费，稀缺的是审美输入。

把活拆成四遍

  1. 定方向（人）：写一段话的简报——给谁用、想要的一个形容词和拒绝的一个形容词、一个参考产品、信息密度。NN/g 对 AI 设计工具的测试显示，提示里没有真实上下文时，产出几乎都是通用模板。
  2. 铺变体（AI）：让 v0 或 Claude 一次给 4–6 个刻意不同的方向，而不是一个"最好"的页面。多样性才是生成器的长处。
  3. 挑选（人）：选定一个，再用具体语言指出问题，比如"行宽超过 80 字符""两个强调色在打架"。
  4. 打磨（AI + 人）：把意见喂回去，或者跑 impeccable、baseline-ui 这类走查 skill，最后 10% 手工收尾。

我们的看法

最大的收益不在生成，而在约束文件：一份简短的 DESIGN.md，写清 token、间距刻度和禁用样式，让每个 Agent 先读它。一次好决定就能变成一百个一致的页面。在 UI Hub 里筛选「Skill」就能找到现成的。

Every AI UI generator converges on the statistical middle of its training data: centred hero, three feature cards, a purple gradient. That is not a bug, it is what "most likely next token" means. The practical consequence is that speed is free and taste is the scarce input.

Split the job into four passes

  1. Direction (human). Write a one-paragraph brief: audience, one adjective you want and one you refuse, a reference product, density level. NN/g's testing of AI design tools found outputs were generic unless the prompt carried real context.
  2. Exploration (AI). Ask v0 or Claude for 4–6 deliberately different directions, not one "best" page. Diversity is where generators shine.
  3. Curation (human). Pick one, then name what is wrong in concrete terms: "line length over 80ch", "two accent colours competing".
  4. Polish (AI + human). Feed those notes back, or run a critique skill such as impeccable or baseline-ui, then do the last 10% by hand.

Our take

The biggest win is not generation but constraint files: a short DESIGN.md with tokens, spacing scale and banned patterns that every agent reads first. It turns one good decision into a hundred consistent screens. On UI Hub, filter by Skill to find ready-made ones.

Checklist

  • Brief has a "never" list
  • Ask for variants, not a page
  • Critique with named problems
  • Lock decisions into tokens
