An agent skill is a folder with a SKILL.md the agent reads when the task matches its description. For design, that means opinions survive between sessions instead of living in one long prompt.

A working stack

  1. Direction: frontend-design or taste-skill before writing code. They push a committed aesthetic and ban the usual tells.
  2. Craft: emil-design-eng for motion and micro-interaction judgement.
  3. Audit: impeccable, baseline-ui and web-design-guidelines after a draft exists.
  4. Redesign: redesign-skill when upgrading an existing site.

Our take

Do not load everything at once. Overlapping skills give conflicting advice. Use one direction skill, one craft skill and one audit skill per task. Write project-specific "never" rules in AGENTS.md so they override generic taste.
