Build a dark SaaS pricing page

Filter
type=library, pricing=free, ct ∋ card|button|layout, tags ∋ React; then type=style with vs ∋ dark-tech|minimal and ct ∋ card for the look.
Choose
shadcn/ui (+ shadcn/ui Blocks for the pricing section), Radix Primitives underneath, Magic UI number ticker for one accent moment.
Tokens
bg #06070b, surface #10131a, ink #f3f5fb, one accent #67e8f9, radius 12, Geist 14/20, tabular numbers for prices.
Skills order
taste-skill (direction) → emil-design-eng (toggle + hover motion ≤ 200ms ease-out) → impeccable + baseline-ui + accessibility.
Verify
monthly/annual toggle keyboard-operable · focus-visible on CTAs · 4.5:1 contrast on muted text · 375px stacks tiers · reduced motion disables ticker · light theme still works.

Add a fancy-but-restrained landing hero

Filter
type ∈ effect|library, vs ∋ motion, ct ∋ background; pricing=free.
Choose
ONE effect: Aceternity spotlight or Magic UI beams; Motion for entrance; no second effect on the page.
Skills order
frontend-design → emil-design-eng → web-design-guidelines + performance.
Verify
LCP < 2.5s, effect paused under prefers-reduced-motion, text readable over effect in both themes.

Audit an existing admin dashboard

Filter
type=style, vs ∋ enterprise, ct ∋ table|nav|form to collect reference demos.
Skills order
redesign-skill → baseline-ui → accessibility → web-quality-audit.
Verify
table header sticky, row focus, empty/loading/error states, 24px targets, dark mode parity.

✓ Do

  • Pick ONE library and ONE visual style per product
  • Lock tokens (CSS variables) before pages
  • Prefer pricing=free + permissive licences for shipped code
  • Use type=style demos to match a concrete look
  • At most one hero effect per page
  • Verify light/dark, 375px, keyboard, reduced motion
  • Cite resources (name + URL) in your PR

✕ Don’t

  • Mix three component libraries in one UI
  • Copy paid / Pro source or hotlink preview images
  • Stack gradients, glass and glow together
  • Use clickable divs or remove focus outlines
  • Animate frequent actions or exceed ~300ms in UI
  • Trust a screenshot: always open the original url
  • Invent licences or affiliate links

FAQ

What is UI Hub?

A free, curated directory of 2376 public UI resources: 119 component libraries, 1924 component style demos with light/dark screenshots, 68 design skills for AI agents, plus effects, templates, specs and tutorials. It links to original sites and never hosts paid source code.

How do I find a component in a given style?

Load https://siinxu.github.io/ui-resource-hub/api/resources.json and filter by ct (component kind, e.g. "dialog") and vs (visual style, e.g. "minimal" or "motion"). type="style" entries are concrete component demos with a libName and page URL; type="library" entries are whole libraries with install info on the site.

Which skills should an agent use for good UI?

One direction skill (frontend-design or taste-skill), emil-design-eng for motion and interaction polish, then impeccable, baseline-ui, web-design-guidelines and accessibility as an audit pass. See https://siinxu.github.io/ui-resource-hub/api/skills.json.

Can I copy the code?

Open-source libraries can be used under their own licenses (MIT, Apache-2.0 etc.); the card shows the original link. Paid tiers (marked paid/freemium) must be bought from the original vendor.

How often is it updated?

Daily via a GitHub Actions job that adds new UI repositories and tools from GitHub, awesome-shadcn-ui and Hacker News. Nothing is deleted. Last update: 2026-10-14 08:54 UTC.
