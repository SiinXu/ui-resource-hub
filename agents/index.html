Workflow

  1. Fetch api/resources.json; filter by ct (component kind) and vs (visual style), prefer pricing: free.
  2. Pick one direction skill (frontend-design or taste-skill) and lock tokens: font, spacing scale, radius, one accent, light + dark.
  3. Choose components: type: library for code, type: style demos for the concrete look; open the original URL for install and source.
  4. Use the card's copyable Prompt as a starting spec; add layout, states, real content and an "avoid" list.
  5. Polish motion with emil-design-eng; audit with impeccable, baseline-ui, web-design-guidelines, accessibility.
  6. Verify in a browser: light/dark, 375 px, keyboard, reduced motion. Cite the resources you used.

FAQ

What is UI Hub?

A free, curated directory of 2376 public UI resources: 119 component libraries, 1924 component style demos with light/dark screenshots, 68 design skills for AI agents, plus effects, templates, specs and tutorials. It links to original sites and never hosts paid source code.

How do I find a component in a given style?

Load https://siinxu.github.io/ui-resource-hub/api/resources.json and filter by ct (component kind, e.g. "dialog") and vs (visual style, e.g. "minimal" or "motion"). type="style" entries are concrete component demos with a libName and page URL; type="library" entries are whole libraries with install info on the site.

Which skills should an agent use for good UI?

One direction skill (frontend-design or taste-skill), emil-design-eng for motion and interaction polish, then impeccable, baseline-ui, web-design-guidelines and accessibility as an audit pass. See https://siinxu.github.io/ui-resource-hub/api/skills.json.

Can I copy the code?

Open-source libraries can be used under their own licenses (MIT, Apache-2.0 etc.); the card shows the original link. Paid tiers (marked paid/freemium) must be bought from the original vendor.

How often is it updated?

Daily via a GitHub Actions job that adds new UI repositories and tools from GitHub, awesome-shadcn-ui and Hacker News. Nothing is deleted. Last update: 2026-10-14 08:54 UTC.
